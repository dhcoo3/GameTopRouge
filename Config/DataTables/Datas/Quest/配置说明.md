# 任务配置说明

任务与目标使用 Luban Excel 数据表；运行时不读取 JSON。源表在当前目录，文本在 `../#Localization.xlsx`，任务枚举在 `../__enums__.xlsx`。

## 表的职责

| 表 | 配置内容 |
| --- | --- |
| `#QuestDefinition.xlsx` | 任务编号、章节/主支线分类、标题与说明、本任务的开放方式、前置任务、简报 Key |
| `#QuestObjectiveGroup.xlsx` | 同一任务的阶段顺序，以及本阶段必须完成的目标数量 |
| `#QuestObjective.xlsx` | 调查、对话、击杀、收集目标和目标来源 |
| `#QuestReward.xlsx` | 任务完成后发放的道具 ID、数量和顺序 |

主表文件名使用 `QuestDefinition`，生成类为 `cfg.Quest.QuestDefinition`。Luban 若生成名为 `Quest` 的类，会与 `cfg.Quest` 命名空间冲突。任务主键使用 1600000 段，目标组 1610000 段，目标 1620000 段，奖励 1630000 段，固定地图物件 1640000 段；新增条目前先检查 `各类ID说明.txt` 和本表的重复 ID。

## 目标来源

- `InspectObject`：填写来源地图、固定摆放实例 ID；如需先播放检查反馈对话，再填写 Dialogue ID。
- `CompleteDialogue`：填写地图、NPC ID 和该 NPC 配置的 Dialogue ID。
- `KillEnemy`：填写敌人配置 ID；当前 PvE 帧同步不提供服务端可验证的击杀事实。
- `CollectItem`：填写 TaskMarker 摆放实例、物品 ID 和每次交互的收集数量。

调查和收集目标必须与 `MapData.Objects` 中一个 `TaskMarker` 双向绑定：物件摆放的 `objectiveId` 要指向目标 ID，目标中的来源地图和摆放实例也必须指回同一条摆放。`SceneProp` 的 `objectiveId` 必须保持为 0。

在 Unity 菜单 `Tools > 地图 > NPC 与传送点编辑器` 中打开目标地图，添加或选中固定物件，在 Inspector 填写“绑定目标 ID”，然后保存地图配置。旧摆放字符串可以只有 10 个字段，编辑器读取时会按 `objectiveId=0` 兼容；保存后会写出第 11 个字段。复制任务标识时会清空目标 ID，避免两个摆放点绑定同一个目标。

## 文案、生成与检查

任务名称、说明、简报、目标提示和完成记录使用 `#Localization.xlsx` 的稳定 Key；每个 Key 都要填写简体中文、繁体中文和英文。不要把玩家可见文案直接写进目标表。

保存 Excel 与地图数据后，在 `Config` 目录运行：

```sh
python3 validate_quest.py
./gen.sh
```

`gen.sh` 会运行任务和对话配置校验，并同时生成客户端与服务端 Luban 表、枚举与二进制文件。生成的 C# 和 `.bytes` 文件不要手改。

当前配置覆盖 M00、M01；尚未确定的 M01 线索点、M02 以后任务与奖励不预填示例数据，等剧情及地图交互点确认后再录入。

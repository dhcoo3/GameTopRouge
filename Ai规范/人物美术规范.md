# 人物美术规范

本规范以 [骑士待机序列图](../Client/GameTopRouge/Assets/SmallScaleInt/TopDown%202D%20pixel%20Characters%20pack%201/Spritesheets/1Knight/Idle.png) 为基准，约束俯视角 2D 像素人物的设计、动画和导入。

## 角色风格

- 采用清晰、紧凑的俯视角像素造型，整体比例、像素密度和轮廓细节与参考骑士保持协调。
- 角色应有可快速识别的职业剪影；头部、躯干、四肢和装备在实际游戏显示尺寸下仍须区分。
- 使用有限的暗色调塑造角色主体，并以浅色护甲或装备高光建立与暗色场景之间的对比。
- 轮廓边缘保持清晰，避免柔化、抗锯齿或非像素风的渐变处理。
- 装备、武器和装饰应支持角色身份辨识，不堆叠过多细碎元素。

## 视角与朝向

- 角色采用俯视斜角视图，头、肩、躯干、盾牌和武器的表现应符合该视角。
- 八方向动画中角色的体型、装备位置和朝向变化保持连续；正反向或左右向不可出现无故换手、装备跳位或比例突变。
- 面向不同方向时保持脚底接地点稳定，角色中心不因单帧轮廓差异而明显漂移。
- 武器和盾牌需在各方向正确遮挡身体，并避免穿透身体或错误地遮挡关键轮廓。

## Sprite Sheet 与动画

- Sprite Sheet 按统一行列组织；同一动作的帧尺寸、帧间距、透明边界和朝向顺序必须一致，并在资源说明中注明布局。
- 每帧角色应在一致的逻辑画布和脚底基准线上绘制；透明留白可以存在，但不得导致动画播放时抖动。
- 待机循环表现轻微、自然的呼吸或姿态变化，动作幅度克制；循环首尾应平滑衔接。
- 行走、攻击、受击等动作应有清楚的预备、发力和收势阶段；帧间动作连续，不突然改变重心或武器轨迹。
- 动画帧数和播放速度以实际游戏观感为准，避免待机过于躁动或动作快到无法辨认。
- 保留透明背景，不将预览底色或场景背景烘焙进角色图像。

## 与场景的适配

- 人物明度和局部对比应足以在参考场景的暗色地面上识别；不得依赖大面积纯白高光。
- 角色主色与场景保持区分，同时避免饱和度高到破坏整体氛围。
- 角色脚底、阴影和地面的接触关系清楚；阴影不能误导碰撞边界或遮挡脚部动作。
- 多个角色同屏时，通过剪影、装备或少量强调色区分阵营和职业，不改变基础画风。

## 导入与验收

- 导入 Unity 后核对 Sprite Mode、切片网格、Pixels Per Unit、过滤模式、压缩和透明通道设置。
- 以游戏实际镜头和缩放比例检查八方向播放，确认无帧偏移、裁切、错序、边缘模糊和循环跳帧。
- 确认待机、移动及战斗动作中角色脚底位置稳定，武器与身体的遮挡关系正确。
- 在参考场景中检查角色可读性、色彩融合度和像素密度；不符合时调整素材或导入参数后再验收。

# 服务器代码规范

本规范说明服务器代码的目录职责、启动及认证和帧同步处理结构。通用 C# 注释与质量要求见[通用代码规范](通用代码规范.md)，运行参数和构建入口见[服务器项目配置](服务器项目配置.md)。

## 服务端代码结构与流程

服务端项目位于 `Server/Server.sln`，项目目标框架在各 `.csproj` 中声明为 `net10.0`。

- `Server/Main/Program.cs` 是进程入口：初始化程序集、配置 NLog，并启动 Fantasy.Net。
- `Server/Entity` 放置可被多个服务端程序集共享的实体和组件类型。`Gate/Entity` 下包含玩家和单位实体；`Gate/Compoent` 下包含房间帧同步组件（目录名 `Compoent` 与项目现有拼写一致）。
- `Server/Hotfix/OnCreateScene_Config.cs` 在 Gate 场景创建时添加帧同步组件。
- `Server/Hotfix/Auth` 提供 HTTP 游客认证、当前登录授权和 MongoDB 一次性票据存储。登录处理器验证票据取得玩家身份，再创建或加载玩家并绑定唯一会话；帧输入处理器只接收当前认证会话所属房间的输入。
- `Server/Hotfix/Gate/Component/FSManagerComponentSystem.cs` 管理玩家加入与离开、帧定时器、输入序号校验、输入范围限制和逐帧广播。
- 服务端协议代码由共享 `.proto` 源定义生成；协议源文件和导出流程见[通用项目配置](通用项目配置.md)。

当前服务端帧同步按 Gate 场景中的组件状态运行。扩展房间和断线重连逻辑时，应一并检查玩家离场时的计时器、输入队列和序号状态清理。

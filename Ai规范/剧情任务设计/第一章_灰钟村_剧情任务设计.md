# 第一章剧情任务设计：钟声下的死人

## 1. 章节定位

| 项目 | 设计内容 |
| --- | --- |
| 章节名称 | 第一章：钟声下的死人 |
| 地点 | 灰钟村及周边墓园、磨坊、教堂地下 |
| 章节类型 | 村庄调查、轻度探索战斗、人物抉择、首个异常首领战 |
| 预计时长 | 约 90–120 分钟，按玩家探索速度浮动 |
| 核心体验 | 从“调查失踪骑士与夜间钟声”入手，发现村民以亡者承受镇印夜蚀，最终决定如何保全村民并结束仪式 |
| 章节主题 | 悲伤可以解释选择，却不能抹去选择造成的后果 |

玩家在本章中不只是清剿怪物，还要判断谁在隐瞒、谁仍能被救，以及如何对待被错误仪式束缚的亡者。灰钟村事件结束后，主角第一次发现骑士团和圣堂的正式记录可能掩盖了镇印失修的事实。

## 2. 世界与事件背景

灰钟村建在旧战场边缘，村民靠种植黑麦、烧炭和为边境驻军供粮生活。百年前“长夜”灾祸结束后，圣堂在村中教堂地下设置了镇印，以圣灰和导流钉将夜蚀压在地下。

约三周前，驻村神父奥伦发现镇印裂开。他向教区寄出求援信，请求派来镇印修复人员和驱魔骑士。教区退回了信件：灰钟村的维护档案记载镇印已完成检修；承认故障会暴露此前检修记录失实，并使负责区域的圣职人员受到追查。教区遂将裂缝定性为“地方迷信与墓地骚动”，要求奥伦安抚村民，不派援手。

玛拉的丈夫死于边境战争。她得知守墓人赫德掌握一套残缺的“回名礼”，便请赫德让死者短暂回应亲人。赫德自己也失去了儿子，误以为仪式只会让亡者回来一夜，于是协助敲响丧钟。第一名亡者回来后，玛拉要求继续仪式；赫德看见亡者开始遗忘亲人，便偷走钟舌，试图阻止仪式。此时钟声已与镇印裂缝相连，即使没有钟舌也会自行响起。

奥伦起初没有参与回名礼。仪式开始后，他发现归来的亡者正在吸收一部分镇印压力，短期内减缓裂缝扩大。他判断自己还需要几夜时间，才能找到导流钉、圣灰并完成临时修复，于是默许仪式继续。他争取的是完成修复所需的时间，代价却是亡者的记忆逐夜消散。下一次无月之夜临近时，亡者与镇印中的夜蚀即将融合。

### 事件因果链

```text
镇印破裂
  → 奥伦求援信被教区退回
  → 玛拉请赫德执行回名礼
  → 亡者归来，玛拉要求重复仪式
  → 赫德发现仪式伤害亡者，偷走钟舌
  → 奥伦发现亡者暂时缓冲镇印压力，默许仪式拖延
  → 钟声与镇印裂缝融合，村中异常加剧
  → 巡境骑士阿尔文调查后失踪
  → 主角奉命搜索阿尔文并调查异常
```

## 3. 主角为何来到灰钟村

主角不是由玛拉、奥伦或领主府召来。骑士团边境哨站按巡境制度登记骑士的路线和归队时间。巡境骑士阿尔文在例行离站报备中记录了灰钟村夜间丧钟持续响起、村民闭门不出，并表示会入村核查。他随后没有按约定时间返回，也没有完成下一次巡境签到。

边境哨站据此启动失联巡骑搜寻程序。主角收到骑士团巡境队长的正式命令，前往灰钟村寻找阿尔文，核实其最后记录中的异常，并判断是否需要封锁镇印。骑士团掌握的是阿尔文的巡境记录与失联事实，**并不知道奥伦曾给教区写信**。主角进入教堂调查后，才会发现那封被退回的信。

**派遣令：**

> “巡境骑士阿尔文未按期归队。其最后一次离站记录提到灰钟村夜间钟鸣及村民闭户。前往搜寻阿尔文，核实异常来源。若确认镇印受损，立即封锁现场并提交报告。”

阿尔文在村中发现教堂地下通道后独自进入镇印室。他在负钟者形成时试图关闭内门，被污染根索拖入地下。最终战后，主角在镇印室找到他的断裂徽记、巡境记录和染有黑泥的剑。遗体不完整，骑士团据此将其列为殉职；阿尔文的记录成为后续追查维护档案的第一份证据。

## 4. 灰钟村场景结构

村庄使用环形道路，教堂钟楼是主要地标。主路从村口经过广场连接教堂；支路通往民居、磨坊和北坡墓园。教堂地下是最终战区域。白天村民忙于封门和搬运物资，夜间亡者循固定路线回家。

| 区域 | 关键表现 | 任务用途 |
| --- | --- | --- |
| 村口 | 骑士团旧巡境记号、泥泞车辙、无人回应的门铃 | 建立阿尔文最后路线；章节入口与撤离方向 |
| 广场 | 村民回避谈论钟声；公告栏上的征兵名单 | 认识玛拉；调查后触发公开对质 |
| 艾妲家 | 第二套餐具、未喝过的热汤、儿童身高刻痕 | 触发托马斯与莉娅支线；展示亡者仍保留日常习惯 |
| 守墓人小屋 | 仪式残页、钟楼钥匙、赫德藏起的阿尔文记录 | 指向墓园并解释回名礼 |
| 北坡墓园 | 新翻泥土、墓碑上的随葬物、污染根须 | 首次墓泥爬行者战；救出赫德 |
| 磨坊与水渠 | 停转水轮、黑水、被根须缠住的导流钉 | 支线清怪与镇印修复材料 |
| 教堂与钟楼 | 被遮住的圣像、钟槌自行摆动、侧室维护簿 | 发现奥伦的求援信和镇印档案 |
| 镇印室 | 裂缝、导流槽、阿尔文遗物、负钟者 | 真相揭露、最终战与结局处理 |

主要环境叙事：亡者进屋后会重复生前动作；餐桌上的食物不会减少；亡者越来越难以认出家人。不要用大量说明文字解释，先让玩家观察这些细节，再通过调查记录和人物对话确认原因。

## 5. 主线任务流程

### C1-M00《失联的巡境骑士》

**接取方式：** 首次进入灰钟村地图时，以单页文字旁白呈现边境哨站记录与巡境队长签发的搜寻命令；确认后把操作交还给玩家。  
**目标：** 寻找阿尔文留下的巡境记号。  
**流程：** 旁白播报命令 → 进入现有灰钟村地图 → 调查村口巡境记号 → 更新阿尔文入村线索 → 开启 M01 并提示向玛拉询问。

> **旁白：**“边境哨站连续两次没有收到巡境骑士阿尔文的签到。巡境队长调阅了他的最后路线记录，签发搜寻命令：”  
> **巡境队长的命令：**“前往灰钟村搜寻阿尔文，核实夜间钟声与村民闭户的情况。若确认镇印受损，立即封锁现场并提交报告。”

**调查记录：**“记号显示阿尔文进入了村庄，出口处没有他的返回标记。”调查记号才算完成 M00；抵达村庄或村口不会自动完成。记录可在本次运行的任务日志中回看。  
**交接目标：** 向玛拉询问阿尔文的下落。  
**信息边界：** 此时主角只确认阿尔文进入村庄且没有返回标记，不知道奥伦的求援信、回名礼、亡者归来或镇印异常的真相。M00 不包含战斗或分支，也不要求返回哨站。

### C1-M01《闭门的村庄》

**目标：** 询问玛拉，调查至少两处异常现场。  
**必经线索：** 村口骑士团记号、民居第二套餐具、墓园湿脚印、教堂门内侧抓痕。  
**流程：** 玛拉接待 → 玩家自由调查 → 根据线索再次质问玛拉 → 等待夜幕。

> **玛拉：**“村里没什么值得骑士留下的事。牲畜丢了几只，旧钟坏了而已。”  
> **主角：**“阿尔文也问过这些事。他去了哪里？”  
> **玛拉：**“他在村里转了一圈。我以为他已经走了。”  
> **主角：**“那就从他最后留下的脚印查起。”

**失败保护：** 至少两项调查即可推进主线；第三项提供额外质问选项，不阻断流程。

### C1-M02《第二副餐具》

**触发：** 夜幕降临，教堂丧钟自行响起。  
**目标：** 跟随归来的亡者，确认其是否攻击村民。  
**流程：** 观察广场村民关门 → 跟踪泥脚印 → 看见托马斯回到艾妲家 → 保护莉娅免受一只失控墓泥爬行者攻击。

托马斯不主动攻击。他坐在旧位置上，试图把一块木料削成木马。短暂演出后，莉娅跑出来喊“爸爸”，艾妲将她拉回屋内。玩家不应在此处被强制要求杀死托马斯。

> **莉娅：**“骑士大人，死人会再死一次吗？”  
> **主角：**“你为什么这样问？”  
> **莉娅：**“爸爸昨天忘了我的名字。他看起来比我还害怕。”

**线索更新：** 亡者并非普通攻击性尸体；钟声响起后，墓园方向的污染生物变得活跃。

### C1-M03《守墓人的钟舌》

**目标：** 找到赫德并取得钟舌。  
**流程：** 搜查赫德小屋 → 沿血迹进入墓园 → 击败 3–5 只墓泥爬行者 → 救出赫德 → 取得布包钟舌与仪式残页。

> **赫德：**“我家守这口钟，是送人走。”  
> **主角：**“这次呢？”  
> **赫德：**“这次……我们站错了方向。”  
> **主角：**“阿尔文来过这里吗？”  
> **赫德：**“来过。他往教堂去了。我没能拦住他。”

赫德承认自己因思念战死的儿子，接受玛拉的请求，执行了一次回名礼。他以为亡者只会回来一夜。玛拉要求继续时，他仍帮助了数次，直到发现亡者遗忘亲人，才偷走钟舌。钟声仍然自行响起，说明异常已从仪式扩展到镇印。

### C1-M04《退回的求援信》

**目标：** 在教堂查明丧钟与镇印的关系，寻找阿尔文。  
**流程：** 进入教堂侧室 → 找到镇印维护簿与奥伦的求援信 → 与奥伦对质 → 前往地窖 → 取得阿尔文巡境记录残页。

**证据内容：**

- 镇印维护簿显示裂缝出现早于亡者归来。
- 奥伦的求援信载明镇印异常与人员请求，信封带有教区退件印记。
- 教区回复称“镇印无恙”，并要求奥伦不要引起恐慌。
- 阿尔文的记录指出，他在教堂地下发现通道后继续深入。

> **主角：**“你早就知道镇印裂了。”  
> **奥伦：**“我写了信。教区退回来了。”  
> **主角：**“之后你为什么没有停下仪式？”  
> **奥伦：**“因为亡者替镇印挡住了一部分夜蚀。我以为只要再有几夜，就能修好它。”  
> **主角：**“你是在争取修复时间。”  
> **奥伦：**“是。我把他们还能记得家人的时间，也算进了代价里。”

**核心真相：** 丧钟把亡者束缚在镇印附近，亡者残存的灵魂暂时吸收夜蚀；每次钟响都加重消耗。镇印裂缝扩大后，亡者与污染会融合成负钟者。

### C1-M05《最后一夜之前》

**目标：** 准备进入镇印室，决定修复镇印或组织撤离。  
**必备主线准备：** 取得赫德手中的钟舌；在磨坊水渠取得导流钉；从教堂圣器室取得圣灰；打通镇印室入口。

到达教堂广场后，主角召集玛拉、奥伦和赫德对质。所有调查线索可用于追问；支线完成情况会补充证词和援助，不改变主线入口。

**方案 A：修复镇印并解除仪式**

- 安装导流钉，投入圣灰，重新稳定镇印。
- 取下丧钟钟舌，完成回名礼的送别部分。
- 亡者得以离开，村庄保留。

**方案 B：组织撤离并封闭教堂**

- 集中村民、粮食与伤病者，沿村口道路撤离。
- 关闭镇印室外门并封锁教堂、墓园区域。
- 村庄被放弃，镇印只能暂时压住污染。

不采用真实时间倒计时；章节的深夜与最终战由玩家完成准备后触发。两种方案均可完成主线，不因未做支线而锁死。

### C1-M06《最后一声钟》

**触发：** 玩家完成准备并进入镇印室。  
**首领：** 负钟者，由污染根索、裹尸布和钟架碎片组成；胸腔内悬着一口残缺小钟，会模仿村民亲人的声音。

**战斗流程：**

1. 躲避钟声冲击，依次破坏三条连接镇印的污染根索。
2. 根索断裂后，负钟者核心暴露；在每轮钟声间隔攻击核心。
3. 支线《没有送出的木马》完成且托马斯被告别后，他短暂恢复意识，替主角挡下一次攻击。
4. 击败负钟者后，按 C1-M05 选择完成镇印修复或组织撤离。
5. 在镇印室废墟中找到阿尔文的断裂徽记、巡境记录与染黑的剑，确认其殉职。

### C1-M07《巡境报告》

**目标：** 返回骑士团哨站，提交阿尔文遗物与调查结果。  
**报告选项：**

| 选项 | 报告重点 | 后续倾向 |
| --- | --- | --- |
| 完整记录 | 如实记录镇印早已失修、教区退信及村民仪式 | 骑士团获得证据，教区提高对主角的关注 |
| 保护村民 | 记录异常已处理，淡化玛拉和赫德的责任 | 灰钟村幸存者信任主角，但报告留下隐瞒风险 |
| 依规追责 | 附上证词并建议审理玛拉、赫德和奥伦 | 强化骑士团纪律立场，村民对主角保持戒备 |

三种报告均完成章节任务。任务完成后，主角因成功处理异常、找回巡境记录而晋升为“巡境骑士”；报告选择改变后续派系关系，不决定能否晋升。

**章节悬念：** 骑士团档案显示灰钟村镇印已于今年春季完成检修，状态正常。主角带回的维护簿却明确记载镇印早已开裂，正式档案与现场证据互相矛盾。

## 6. 支线任务

### C1-S01《没有送出的木马》

**委托人：** 莉娅；关联人物：托马斯、艾妲。  
**目标：** 找回托马斯生前为莉娅做的木马与信件。  
**流程：** 询问托马斯的含混记忆 → 搜索村口废弃军需车 → 击败两只污染野犬 → 找到木马和征召前的信 → 将物品交给托马斯或艾妲。

> **托马斯：**“腿还没磨平……会扎她的手。”  
> **主角：**“她已经等了很久。”  
> **托马斯：**“是啊。总说回来再做。”

**影响：** 将木马交给托马斯，他会短暂恢复记忆，在最终战中援助主角；交给艾妲，她会接受丈夫即将离去，并在结尾帮助安排村民。两种处理都不阻断主线。

### C1-S02《磨坊里的黑水》

**委托人：** 布兰。  
**目标：** 查明水渠污染并回收镇印导流钉。  
**流程：** 检查停转水轮 → 进入水渠 → 清除三处污染根须并击杀寄生体 → 发现水源已污染 → 回收导流钉 → 告知布兰结果。

> **布兰：**“我请你修磨坊，你替我关了它。”  
> **主角：**“再磨出的粮食会让人得病。”  
> **布兰：**“那就帮我把剩下的干净粮袋搬走。”

**影响：** 布兰提供干粮和运输车。修复镇印路线下减少村庄物资损失；撤离路线下帮助运输伤病者。未接支线时，导流钉仍能从水渠入口取得。

### C1-S03《未点燃的灯》

**委托人：** 赫德。  
**目标：** 为三座无名墓点灯，辨认战后未能认领的死者。  
**流程：** 从赫德处拿取墓灯 → 根据登记册寻找三座墓 → 点灯并收集散落军牌 → 归还碎片。

> **主角：**“你不知道他们是谁？”  
> **赫德：**“不知道。”  
> **主角：**“那灯上刻什么名字？”  
> **赫德：**“先空着。总比把别人的名字刻上去好。”

**影响：** 赫德愿意在对质时公开完整证词；玩家在墓旁发现与阿尔文巡境路线有关的旧骑士徽记，补充失踪调查线索。

## 8. 关键剧情对话

### 玛拉被揭穿后

> **主角：**“是你要求赫德敲响丧钟。”  
> **玛拉：**“是。”  
> **主角：**“你知道这会伤害他们吗？”  
> **玛拉：**“我只知道第一夜，他回来了。后来我知道得更多，却还是让钟响了。”

### 赫德承认自己的选择

> **主角：**“你知道仪式残缺，为什么还做？”  
> **赫德：**“我以为只敲一次。我儿子没能回来，连名字都没地方刻。我想听他叫我一声。”  
> **主角：**“后来呢？”  
> **赫德：**“后来他们开始忘记活人。我偷了钟舌，却没能让钟停下。”

### 结局告别

> **莉娅：**“你明天还回来吗？”  
> **托马斯：**“不了。”  
> **莉娅：**“那我把门关上了？”  
> **托马斯：**“嗯。夜里冷。”

## 9. 玩法与叙事验收标准

- 玩家能从骑士团失联巡骑搜寻令理解主角为何到村，不需要领主府报案，也不需要骑士团提前知道奥伦的信。
- 玩家在发现退信前，不会被告知奥伦求援；信封的教区退件印记和信件正文能说明拒绝原因。
- 奥伦“争取时间”的目标明确为取得材料并修复镇印；他默许仪式的决定与他的责任同时成立。
- 赫德的帮助由丧子之痛、对残缺仪式的误判及初期仅想让亡者回应一夜构成；发现伤害后主动停止并偷走钟舌。
- 亡者与污染生物区分明确：托马斯等归返者仍有人性，墓泥爬行者和负钟者是夜蚀形成的敌对异常。
- 主线关键证据至少有两条可获得路径；支线奖励提供援助和情感变化，不锁死主线结局。
- 修复与撤离两种方案都能完成章节；没有隐藏倒计时导致玩家探索时村民突然死亡。
- 章节结尾回收阿尔文失联调查，并留下维护档案被篡改或失实的后续主线钩子。

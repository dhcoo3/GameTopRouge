# 客户端项目配置

本文说明 Unity 客户端的编辑器版本、工程设置、启动资产和连接配置。共用协议和 Luban 生成流程见[通用项目配置](通用项目配置.md)，客户端代码结构与开发规范见[客户端代码规范](客户端代码规范.md)。

## Unity 工程

- 工程路径：`Client/GameTopRouge`。
- 项目记录的 Unity 版本为 `2022.3.62t16`，同时记录团结引擎版本 `1.10.4`。打开工程时使用团队当前认可的对应编辑器版本。
- Unity 平台、构建场景、图形、输入和包设置位于 `Client/GameTopRouge/ProjectSettings`。

## 启动与运行设置

- Unity 编辑器及工程设置位于 `Client/GameTopRouge/ProjectSettings`。修改平台、构建场景、图形、输入或包设置时，使用 Unity 工程设置或对应资产，并检查相关平台差异。
- `Client/GameTopRouge/Assets/AAAGame/ScriptableAssets/Core/AppConfigs.asset` 保存启动流程和运行设置；对应类型定义在 `Client/GameTopRouge/Assets/AAAGame/ScriptsHotfix/ScriptableObject/AppConfigs.cs`。修改流程顺序或类型时，应同步检查 `HotfixEntry` 的流程初始化和相关 Procedure。
- `Client/GameTopRouge/Assets/AAAGame/ScriptsBuiltin/Runtime/ScriptableObject/AppSettings.cs` 定义内置设置类型。资源更新地址、调试开关、语言等运行行为，应先确认其读取位置和默认值，再修改对应设置。
- `AppConfigs.AuthBaseUrl` 保存游客认证服务地址，开发默认 `http://127.0.0.1:20001`。客户端先通过 HTTP 获取连接信息，再使用一次性票据连接 Gate；Gate 地址从服务器 `Fantasy.config` 读取。部署到其他设备时需配置可达地址。

### 当前客户端实现说明

- `GameNetworkComponent` 只管理 Fantasy Scene、Session、KCP 连接和心跳，不能保存玩家身份或决定重连策略。

## 数据表产物

客户端数据表源文件位于 `Config/DataTables`。运行 `Config/gen.bat` 生成后，客户端代码写入 `Client/GameTopRouge/Assets/AAAGame/ScriptsHotfix/DataTable`，二进制数据写入 `Client/GameTopRouge/Assets/AAAGame/DataTable`。完整生成说明见[通用项目配置](通用项目配置.md)。
